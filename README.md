# Kuvaesitys verkkoselaimessa

Linkki toimivaan sovellukseen: [jarvena.github.io/slideshow](https://jarvena.github.io/slideshow)

Minimalistinen verkkosovellus kuvaesityksen pyörittämiseen selaimessa. Osoita kuvakansio omalta laitteelta ja esitys pyörii selaimessa. Kuvat pysyvät kovalevyllä ja selaimessa, sovellus ei lähetä mitään verkkoon.

Oletuksena esitys lisää hieman liikettä esitykseen, zoomaa ja panoroi kuvia esityksen elävöittämiseksi. Esitys sovittaa kuvat näytön kokoon ja täyttää ylimääräisen näyttötilan kuvan teeman mukaisesti.
